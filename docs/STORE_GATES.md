## Gates no API exposes — Play Console or App Store Connect only

### Testing
- **Play internal tester list.** The API attaches Google Groups only; the team's email list must be made in Play Console. Until then every internal release is live but reaches nobody. Internal testing is capped at 100 testers.
- **TestFlight internal groups.** The API refuses tester assignment to them, so beta distribution here runs through an external group, and Apple reviews every build before testers receive it.

### Production
- **Apple: App Privacy details.** The nutrition label cannot be set with an API key.
- **Apple: App Review sign-in.** A login-gated app needs demo credentials entered by hand.
- **Apple: content rights declaration** and the submission itself.
- **Play: content rating questionnaire (IARC)**, **data safety form**, **target audience and content**, **ads declaration**, **app access instructions**, and the **privacy policy URL under App content**. None of these have a Play Developer API surface.
- **Play: the production release itself**, plus any upload-key reset (see MA-015).

Measured platform requirements that currently pass for every built app: Android target SDK 35 or 36, and 64-bit native libraries aligned for 16 KB pages.
